# Getting a prospect to an aha moment in 15m

An interactive marketing site that lets visitors pick a bug they've been burned by — race conditions, deadlocks, out-of-order events, orphaned jobs, data corruption — and walks them through how Antithesis catches and reproduces it. Built with Next.js 16, App Router, and shadcn/ui.

Three views per bug: the buggy code + invariant, a fault-injection tree that shows how Antithesis explores reachable states, and a stepped animation of the verdict that finishes with a "Book a demo" CTA.
